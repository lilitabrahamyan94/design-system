# Colors

All the colours are Figma variables, so use them as design tokens. Source: `src/tokens/colors.json`.

**Two layers.** *Primitives* are the raw palette (`--color-sun-orange-040`). *Semantic* tokens point to primitives and say what a colour is for (`--semantic-text-on-light-primary` → `gray-96`). Components should use semantic tokens.
