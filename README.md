# Design System

React components and design tokens built from the Genesis Figma kit, documented in Storybook.

## Run it

```bash
npm install
npm run storybook        # http://localhost:6006
npm run build-storybook  # static site in storybook-static/
```

## What's inside

| Path | What |
|---|---|
| `src/tokens/*.json` | **Source of truth.** W3C design-token JSON with the Figma variable names |
| `src/tokens/*.css, *.ts` | Generated by `npm run tokens`. Don't edit by hand |
| `src/styles/` | Component CSS (`button.css`, `field.css`, `controls.css`) and `index.css`, which imports everything |
| `src/icons/` | 147 SVG icons + `icons.json` manifest, and the `<Icon>` component |
| `src/components/` | React components: Button, ButtonGroup, Input, TextArea, Select, Toggle, Checkbox, Radio, RadioGroup, Tabs, Uploader, FileItem, DatePicker |
| `src/stories/` | One story per Figma state, plus a Playground with live controls |
| `src/docs/` | Introduction, Colors, Typography, Icons and Accessibility pages |

## Use in an app

```tsx
import './src/styles/index.css';
import { Button, Input } from './src';

<Input label="Email" required error="Enter a valid email" />
<Button variant="primary">Save</Button>
```

## Checks

- `npm run typecheck`: TypeScript
- `python3 scripts/check-stories.py http://localhost:6007`: opens every story and docs page in the built Storybook, and reports JS errors and axe (WCAG 2.2 AA) violations. The only open violations are colour contrast from the Figma palette. See *Foundations / Accessibility*.
